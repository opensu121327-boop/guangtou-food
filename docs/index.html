🛡️ 你的權益（請安心申訴）
依《職業安全衛生法》，雇主應預防執行職務遭受身體或精神不法侵害（職場霸凌），並提供申訴管道。
・保密：本申訴僅由老闆本人查看與處理，不會公開給其他同事或店長。
・不報復：公司不得因你提出申訴而對你有任何不利處分（如調職、減薪、刁難）。
・可匿名：你可以選擇不留姓名。
・若涉及肢體暴力、傷害或立即危險，請先確保安全並視情況報警 110。
📞 政府外部申訴管道（可直接聯繫）
・勞動部 1955 勞工諮詢申訴專線（24 小時・全國・免付費）
・各縣市政府勞工局／處（當地勞動主管機關，可申訴、申請勞資爭議調解）
・勞動部 職業安全衛生署（職場不法侵害預防之中央主管機關）
＊外部管道獨立於公司，你可同時或單獨使用。
